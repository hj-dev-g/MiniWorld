# MiniWorld Reels Editor

브라우저 기반 Instagram Reels 편집기 프로토타입입니다. 영상·이미지·오디오는 서버에 업로드하지 않고 브라우저에서 처리하고 원본과 편집 내용을 로컬에 저장합니다.

## 실행 (Windows CMD)

저장소 루트에서는 먼저 편집기 브랜치와 `editor` 폴더로 이동합니다.

```bat
git switch feature/reels-editor
git pull origin feature/reels-editor
cd editor
npm ci
npm run dev
```

터미널에 표시된 `Local` 주소(기본 `http://localhost:5173/`)를 브라우저에서 엽니다. 배포된 편집기는 [MiniWorld Editor](https://miniworld-reels-editor.kor-hjkang.chatgpt.site)에서 열 수 있습니다. 현재 소유자 계정에만 공유되어 있습니다.

## 현재 구현

- React + TypeScript + Vite + Zustand
- 1080×1920 / 30fps, 9:16 영상 프리뷰
- 여러 로컬 MP4 / WebM / MOV 가져오기·이어붙이기·재사용 (재생/내보내기는 브라우저 코덱 지원에 따름)
- 프로젝트 이름 편집, IndexedDB 자동 저장과 새로고침 후 원본 미디어 복원
- `.miniworld` 프로젝트 파일에 원본 영상·음악·이미지와 편집 설정을 함께 저장/불러오기
- 720×1280 / 1080×1920, 30fps H.264/AAC MP4 합성 내보내기, 진행률·취소, 워터마크 없음
- Play / Pause, ±1초 이동, 타임라인 클릭으로 탐색, 타임라인 확대/축소
- 선택 클립을 재생 헤드에서 분할 (최소 1프레임)
- 클립 드래그 이동, 양쪽 핸들 트림, 인접 클립/재생 헤드 스냅
- 원본 영상 범위와 타임라인 시간 분리, 트림 후 구간 복원 가능
- 영상 트랙에서 겹침 방지, 이동 후 시간순 정렬
- Delete: 빈 구간 유지, 삭제 + 당기기: 같은 트랙의 뒤 클립만 당김
- 영상 빈 구간의 검은 화면, 활성 BGM이 없으면 무음 재생, 프로젝트 끝 자동 정지
- 선택 클립의 타임라인 시작/길이/원본 구간 표시
- 텍스트 추가, 여러 줄 내용, 폰트/크기/색상/정렬/굵게/그림자 편집
- 1080×1920 캔버스 좌표로 자막 위치 저장, 프리뷰 드래그/방향키/숫자로 이동
- 자막 선택 테두리는 기본 숨김, 프리뷰 상단 버튼으로 표시/숨김 전환
- 자막 표시 구간 이동/트림/분할/삭제, 동시에 여러 자막 표시
- PNG / JPEG / WebP 이미지 가져오기, PNG 투명 배경 유지
- 이미지 재사용, 프리뷰 이동/모서리 크기 조절, 원본 비율 유지, 불투명도 편집
- 이미지 표시 구간 이동/트림/분할/삭제, 여러 이미지와 자막 동시 표시
- 로컬 BGM 가져오기·재사용, 별도 오디오 트랙의 이동/트림/분할/삭제
- BGM과 영상 원본 소리의 클립별 볼륨(0–100%)·음소거, 겹친 오디오 동시 재생
- 프로젝트 시각에 맞춘 오디오 탐색·재생·정지, 오디오만으로도 편집/재생 가능
- Undo / Redo (최근 100회), 입력/드래그 묶음 단위 실행 취소
- 영상 없이 검은 배경에 자막과 이미지 편집/재생
- 타임라인 엔진과 편집 상태 자동 테스트, GitHub Actions 빌드

## 편집 방법

1. 여러 영상을 추가하면 영상 트랙 끝에 차례대로 이어붙입니다. 원본 목록을 클릭하면 다시 사용할 수 있습니다. 기존 자막·이미지·음악은 유지됩니다.
2. 타임라인 눈금을 클릭해 원하는 시각으로 이동하고 `Split`으로 나눕니다.
3. 클립 몸통을 드래그해 이동합니다. 가장자리 핸들은 사용 구간을 조절합니다.
4. `Delete`로 제거하거나 `삭제 + 당기기`로 뒤 클립을 당깁니다.
5. 왼쪽 `텍스트` → `텍스트 추가`를 누르면 현재 시각에 최대 3초짜리 자막이 생깁니다. 프로젝트 끝에서는 3초를 연장합니다.
6. 오른쪽 속성 패널에서 내용과 스타일을 바꾸고, 프리뷰의 자막을 드래그해 위치를 잡습니다. 자막 클립은 타임라인에서 별도 행으로 표시됩니다.
7. 왼쪽 `이미지` → `이미지 추가`로 PNG/JPEG/WebP를 가져옵니다. 프리뷰 모서리로 크기를 바꾸고 오른쪽에서 위치·크기·불투명도를 편집합니다. 원본 비율은 유지됩니다. 목록 이미지를 클릭하면 현재 위치에 다시 추가됩니다.
8. 왼쪽 `오디오` → `BGM 추가`로 파일을 가져옵니다. 현재 시각부터 프로젝트의 남은 길이까지 추가하며, 파일이 더 짧으면 원본 길이를 사용합니다. 빈 프로젝트나 프로젝트 끝에서는 원본 전체 길이로 추가합니다. 오른쪽에서 선택한 클립의 볼륨·음소거를 바꾸고 타임라인에서 구간을 조절합니다. 영상 클립을 선택하면 원본 소리도 조절할 수 있습니다.
9. `Undo` / `Redo` 버튼으로 되돌리거나 다시 적용합니다. 텍스트 입력란에서는 해당 입력란의 기본 단축키가 우선됩니다.

클립/핸들에 포커스가 있을 때 방향키는 1프레임, Shift+방향키는 10프레임 단위로 편집합니다. Alt+드래그는 스냅을 해제합니다. Delete/Backspace는 일반 삭제, Shift+Delete/Backspace는 삭제 후 당기기입니다.

프리뷰에서 자막이나 이미지에 포커스가 있으면 방향키는 위치를 1px, Shift+방향키는 10px씩 조절합니다. 위치와 글자 크기는 원본 캔버스 기준이며, 프리뷰 크기가 바뀌어도 유지됩니다. 폰트는 사용자 컴퓨터에 설치된 폰트를 사용합니다.

편집기 Undo는 Ctrl/Cmd+Z, Redo는 Ctrl+Y 또는 Ctrl/Cmd+Shift+Z입니다. 재생/탐색/선택은 편집 이력에 쌓이지 않습니다. 새로운 변경을 하면 Redo 이력이 초기화됩니다. 자막 입력·크기·색상·위치 필드는 포커스를 벗어날 때 한 묶음으로 기록되며, 프리뷰 드래그는 한 번에 되돌릴 수 있습니다. 드래그 중 Escape 또는 포인터 취소 시 위치 변경을 취소합니다. 새 영상을 추가해도 기존 편집과 Undo/Redo 이력은 유지됩니다. 프로젝트 파일을 불러오면 해당 프로젝트로 교체되며 Undo/Redo 이력은 초기화됩니다.

프로젝트 길이는 마지막 클립 끝까지입니다. 중간 빈 구간은 유지되며 마지막 클립 뒤 빈 구간은 제거됩니다. 영상이 없는 시각에는 검은 배경에 활성 자막과 이미지가 표시됩니다. 자막은 이미지 위에 표시됩니다. 각 영상 클립은 자신의 원본을 참조합니다. 영상 경계를 지나도 프로젝트 재생은 계속되며, 탐색·트림·분할 후에도 해당 원본 구간을 사용합니다.

이미지·오디오 삭제나 추가 실행 취소 후에도 자산 목록의 원본은 유지되어 다시 사용할 수 있습니다. 프로젝트 전체를 교체하면 이전 미디어 URL을 해제합니다. 원본 파일은 IndexedDB에 저장되어 새로고침 후 복원됩니다. 자동 저장은 같은 브라우저·같은 주소에서만 복원되며 브라우저 데이터 삭제 시 사라집니다. 다른 브라우저/컴퓨터로 옮기려면 프로젝트 파일로 저장하세요.

BGM의 초기 볼륨은 50%, 영상은 100%입니다. 음소거를 해제하면 기존 볼륨을 유지합니다. 분할된 클립은 소리 설정을 복사하고 이후에는 각각 편집할 수 있습니다. 볼륨 슬라이더의 변경은 포커스를 벗어날 때 한 번의 Undo로 기록됩니다.

오디오 형식은 브라우저 코덱 지원에 따릅니다(MP3/WAV/M4A/OGG/WebM/FLAC 등). 잘못된 파일은 기존 편집을 유지하며 오류를 표시합니다. 파형, 자동 반복, 페이드는 아직 지원하지 않습니다. MP4 내보내기는 편집한 원본 소리와 BGM을 합성합니다. 현재 오디오는 브라우저 미디어 재생으로 동기화하는 프리뷰이며 프레임 단위 편집과 별개로 샘플 단위 정밀 재생은 제공하지 않습니다.

## 저장·내보내기

편집 변경 후 상단의 자동 저장 상태를 확인하세요. 재생 중 매 프레임을 저장하지 않으며, 마지막 편집 시점의 재생 위치가 복원될 수 있습니다. 원본 Blob은 별도 IndexedDB 저장소에 한 번 기록하고 이후 자막/클립 수정에서는 프로젝트 정보만 갱신합니다. Web Locks를 지원하는 브라우저에서는 한 탭만 자동 저장하며 다른 탭은 파일 저장만 사용합니다. 저장 공간 부족이나 브라우저 제한 시 오류를 표시하며 파일 저장은 계속 사용할 수 있습니다.

`프로젝트 저장`은 원본을 포함한 ZIP 기반 `.miniworld` 파일을 다운로드합니다. 원본 합계 512MB까지 지원합니다. `불러오기`는 형식·클립 범위·원본 미디어를 검증한 후 교체합니다. 손상된 파일이나 이 브라우저가 읽지 못하는 원본은 기존 편집을 유지합니다. 버전 1은 1080×1920 / 30fps 프로젝트만 지원합니다.

`MP4 내보내기`에서 해상도를 선택합니다. 프로젝트 10분까지 지원하며 자막·이미지·영상 빈 구간·클립별 음량/음소거·겹친 BGM을 합성합니다. 선택 테두리/이미지 핸들은 포함되지 않습니다. MP4 H.264 인코딩은 최신 Chrome/Edge를 권장합니다. 지원하지 않는 코덱은 오류를 표시합니다. AAC 인코딩이 없는 브라우저에서는 별도 WebAssembly 인코더를 사용합니다. AAC 프레임 패딩으로 파일 길이가 수십 ms 늘어날 수 있습니다. 처리 속도/메모리는 기기와 프로젝트 크기에 따라 달라집니다.

폰트는 해당 컴퓨터에 설치된 것을 사용하므로 다른 컴퓨터에서 프로젝트를 열면 글꼴과 줄바꿈이 달라질 수 있습니다. 현재 캔버스 자막 합성은 DOM 프리뷰와 다른 렌더러를 사용해 줄바꿈·그림자에 작은 차이가 있을 수 있습니다.

내장 음악·타사 릴스·CapCut 템플릿은 번들하지 않습니다. 사용자가 가져온 미디어로 편집합니다. 사용한 오픈소스와 라이선스는 `public/licenses/NOTICE.txt`에서 확인할 수 있습니다.
