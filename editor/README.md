# MiniWorld Reels Editor

브라우저 기반 Instagram Reels 편집기 프로토타입입니다. 영상·이미지·오디오는 서버에 업로드하지 않고 현재 브라우저에서만 사용합니다.

## 실행 (Windows CMD)

저장소 루트에서는 먼저 편집기 브랜치와 `editor` 폴더로 이동합니다.

```bat
git switch feature/reels-editor
git pull origin feature/reels-editor
cd editor
npm ci
npm run dev
```

터미널에 표시된 `Local` 주소(기본 `http://localhost:5173/`)를 브라우저에서 엽니다. 다른 컴퓨터에서도 접근하는 배포 주소는 아직 제공하지 않습니다.

## 현재 구현

- React + TypeScript + Vite + Zustand
- 1080×1920 / 30fps, 9:16 영상 프리뷰
- 로컬 MP4 / WebM / MOV 선택 (실제 재생은 브라우저 코덱 지원에 따름)
- Play / Pause, ±1초 이동, 타임라인 클릭으로 탐색, 타임라인 확대/축소
- 선택 클립을 재생 헤드에서 분할 (최소 1프레임)
- 클립 드래그 이동, 양쪽 핸들 트림, 인접 클립/재생 헤드 스냅
- 원본 영상 범위와 타임라인 시간 분리, 트림 후 구간 복원 가능
- 영상 트랙에서 겹침 방지, 이동 후 시간순 정렬
- Delete: 빈 구간 유지, 삭제 + 당기기: 같은 트랙의 뒤 클립만 당김
- 영상 빈 구간의 검은 화면, 활성 BGM이 없으면 무음 재생, 프로젝트 끝 자동 정지
- 선택 클립의 타임라인 시작/길이/원본 구간 표시
- 텍스트 추가, 여러 줄 내용, 폰트/크기/색상/정렬/굵게/그림자 편집
- 1080×1920 캔버스 좌표로 자막 위치 저장, 프리뷰 드래그/방향키/숫자로 이동
- 자막 선택 테두리는 기본 숨김, 프리뷰 상단 버튼으로 표시/숨김 전환
- 자막 표시 구간 이동/트림/분할/삭제, 동시에 여러 자막 표시
- PNG / JPEG / WebP 이미지 가져오기, PNG 투명 배경 유지
- 이미지 재사용, 프리뷰 이동/모서리 크기 조절, 원본 비율 유지, 불투명도 편집
- 이미지 표시 구간 이동/트림/분할/삭제, 여러 이미지와 자막 동시 표시
- 로컬 BGM 가져오기·재사용, 별도 오디오 트랙의 이동/트림/분할/삭제
- BGM과 영상 원본 소리의 클립별 볼륨(0–100%)·음소거, 겹친 오디오 동시 재생
- 프로젝트 시각에 맞춘 오디오 탐색·재생·정지, 오디오만으로도 편집/재생 가능
- Undo / Redo (최근 100회), 입력/드래그 묶음 단위 실행 취소
- 영상 없이 검은 배경에 자막과 이미지 편집/재생
- 타임라인 엔진과 편집 상태 자동 테스트, GitHub Actions 빌드

## 편집 방법

1. 영상을 추가합니다. 새 영상 선택 시 현재 클립들은 교체됩니다.
2. 타임라인 눈금을 클릭해 원하는 시각으로 이동하고 `Split`으로 나눕니다.
3. 클립 몸통을 드래그해 이동합니다. 가장자리 핸들은 사용 구간을 조절합니다.
4. `Delete`로 제거하거나 `삭제 + 당기기`로 뒤 클립을 당깁니다.
5. 왼쪽 `텍스트` → `텍스트 추가`를 누르면 현재 시각에 최대 3초짜리 자막이 생깁니다. 프로젝트 끝에서는 3초를 연장합니다.
6. 오른쪽 속성 패널에서 내용과 스타일을 바꾸고, 프리뷰의 자막을 드래그해 위치를 잡습니다. 자막 클립은 타임라인에서 별도 행으로 표시됩니다.
7. 왼쪽 `이미지` → `이미지 추가`로 PNG/JPEG/WebP를 가져옵니다. 프리뷰 모서리로 크기를 바꾸고 오른쪽에서 위치·크기·불투명도를 편집합니다. 원본 비율은 유지됩니다. 목록 이미지를 클릭하면 현재 위치에 다시 추가됩니다.
8. 왼쪽 `오디오` → `BGM 추가`로 파일을 가져옵니다. 현재 시각부터 프로젝트의 남은 길이까지 추가하며, 파일이 더 짧으면 원본 길이를 사용합니다. 빈 프로젝트나 프로젝트 끝에서는 원본 전체 길이로 추가합니다. 오른쪽에서 선택한 클립의 볼륨·음소거를 바꾸고 타임라인에서 구간을 조절합니다. 영상 클립을 선택하면 원본 소리도 조절할 수 있습니다.
9. `Undo` / `Redo` 버튼으로 되돌리거나 다시 적용합니다. 텍스트 입력란에서는 해당 입력란의 기본 단축키가 우선됩니다.

클립/핸들에 포커스가 있을 때 방향키는 1프레임, Shift+방향키는 10프레임 단위로 편집합니다. Alt+드래그는 스냅을 해제합니다. Delete/Backspace는 일반 삭제, Shift+Delete/Backspace는 삭제 후 당기기입니다.

프리뷰에서 자막이나 이미지에 포커스가 있으면 방향키는 위치를 1px, Shift+방향키는 10px씩 조절합니다. 위치와 글자 크기는 원본 캔버스 기준이며, 프리뷰 크기가 바뀌어도 유지됩니다. 폰트는 사용자 컴퓨터에 설치된 폰트를 사용합니다.

편집기 Undo는 Ctrl/Cmd+Z, Redo는 Ctrl+Y 또는 Ctrl/Cmd+Shift+Z입니다. 재생/탐색/선택은 편집 이력에 쌓이지 않습니다. 새로운 변경을 하면 Redo 이력이 초기화됩니다. 자막 입력·크기·색상·위치 필드는 포커스를 벗어날 때 한 묶음으로 기록되며, 프리뷰 드래그는 한 번에 되돌릴 수 있습니다. 드래그 중 Escape 또는 포인터 취소 시 위치 변경을 취소합니다. 새 영상을 불러오면 현재 클립과 이미지·오디오 목록 및 Undo/Redo 이력이 모두 초기화됩니다.

프로젝트 길이는 마지막 클립 끝까지입니다. 중간 빈 구간은 유지되며 마지막 클립 뒤 빈 구간은 제거됩니다. 영상이 없는 시각에는 검은 배경에 활성 자막과 이미지가 표시됩니다. 자막은 이미지 위에 표시됩니다. 현재는 원본 영상 한 개에서 만든 여러 클립을 지원합니다. 새로고침 시 로컬 편집 상태가 초기화됩니다.

이미지·오디오 삭제나 추가 실행 취소 후에도 자산 목록의 원본은 유지되어 다시 사용할 수 있습니다. 새 영상을 가져오거나 편집기를 닫으면 이미지·오디오 자원을 해제합니다. 가져온 파일은 현재 브라우저에서만 사용하며 새로고침 후에는 다시 가져와야 합니다.

BGM의 초기 볼륨은 50%, 영상은 100%입니다. 음소거를 해제하면 기존 볼륨을 유지합니다. 분할된 클립은 소리 설정을 복사하고 이후에는 각각 편집할 수 있습니다. 볼륨 슬라이더의 변경은 포커스를 벗어날 때 한 번의 Undo로 기록됩니다.

오디오 형식은 브라우저 코덱 지원에 따릅니다(MP3/WAV/M4A/OGG/WebM/FLAC 등). 잘못된 파일은 기존 편집을 유지하며 오류를 표시합니다. 파형, 자동 반복, 페이드, 내보내기는 아직 지원하지 않습니다. 현재 오디오는 브라우저 미디어 재생으로 동기화하는 프리뷰이며 프레임 단위 편집과 별개로 샘플 단위 정밀 재생은 제공하지 않습니다.
